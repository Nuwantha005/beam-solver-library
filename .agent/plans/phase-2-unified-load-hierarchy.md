# Phase 2 Implementation Plan — Unified Load Hierarchy & Beam Integration

## 1. Objectives
1. **Design a Unified Load Abstraction (`ILoad` / `BaseLoad`)**:
   Establish a cohesive contract across all applied structural actions: concentrated point forces (`PointLoad`, `Force2D`, `SimpleForce`), distributed loads (`UniformlyDistributedLoad`, `TaperzoidLoad`), and concentrated moments (`MomentLoad` / `Moment`).
2. **Standardize Load Properties & Methods**:
   Every load object must support:
   - Location / bounds (`startLocation`, `endLocation`, or point position $x$).
   - Equivalent resultant force and moment contributions: `getTotalForce()`, `getMomentAround(x)`.
   - Identification tags or predicates (e.g. `LoadType` enum: `POINT`, `DISTRIBUTED`, `MOMENT`).
3. **Upgrade Beam Load Management (`src/objects/beam.ts`)**:
   - Store all loads uniformly in `Beam._loads: ILoad[]`.
   - Provide type-specific accessors: `getPointLoads()`, `getDistributedLoads()`, `getAppliedMoments()`, and general `getLoads()`.
   - Retain backwards-compatibility for `addForce()`, `getForces()`, `setForces()`, `removeForces()`.
4. **Implement Unit Tests**:
   - Unit tests for load hierarchy polymorphism and resultant/moment evaluations.
   - Comprehensive tests for `Beam` load aggregation, boundary validation, and removal.

## 2. Detailed Technical Design

### Step 2.1: Unified Load Interface & Base Classes
- Create `src/objects/Forces/Loads/ILoad.ts`:
  ```typescript
  export enum LoadType {
    POINT = "POINT",
    DISTRIBUTED = "DISTRIBUTED",
    MOMENT = "MOMENT",
  }

  export interface ILoad {
    readonly loadType: LoadType;
    readonly startLocation: number;
    readonly endLocation: number;
    getTotalVerticalForce(): number;
    getTotalHorizontalForce(): number;
    getMomentAround(x: number, y?: number): Moment;
  }
  ```

### Step 2.2: Refactor Existing Load Classes to Implement `ILoad`
1. **`PointLoad` / `BaseForce`**:
   - `startLocation = x`, `endLocation = x`.
   - `loadType = LoadType.POINT`.
   - `getTotalVerticalForce() = getYComponent()`, `getTotalHorizontalForce() = getXComponent()`.
2. **`DistributedLoad` / `UniformlyDistributedLoad` / `TaperzoidLoad`**:
   - `loadType = LoadType.DISTRIBUTED`.
   - `getTotalVerticalForce()`: integrated vertical force (negative if downward).
   - `getMomentAround(x)`: moment generated by the load segment to the left of $x$.
3. **`MomentLoad` (`src/objects/Forces/Loads/MomentLoad.ts`)**:
   - Wraps concentrated couple/moment at location $x$.
   - `loadType = LoadType.MOMENT`.
   - `getTotalVerticalForce() = 0`, `getTotalHorizontalForce() = 0`.
   - `getMomentAround(x)`: produces a step jump in bending moment.

### Step 2.3: Integrate with `Beam` (`src/objects/beam.ts`)
- Add `_loads: ILoad[] = []` to `Beam`.
- `addLoad(load: ILoad | BaseForce | DistributedLoad | Moment): void`
- `getLoads(): ILoad[]`
- `getPointLoads(): BaseForce[]`
- `getDistributedLoads(): DistributedLoad[]`
- `getAppliedMoments(): Moment[]`
- Maintain `addForce(force: BaseForce)` as an alias that maps into `addLoad(force)`.
- Enforce validation: throw `InvalidGeometryError` if load locations fall outside $[0, \text{length}]$.

### Step 2.4: Export & Test
- Update `src/index.ts`.
- Create `test/objects/Forces/Loads/DistributedLoad.test.ts`.
- Create `test/objects/Forces/Loads/MomentLoad.test.ts`.
- Update `test/objects/beam.test.ts`.
